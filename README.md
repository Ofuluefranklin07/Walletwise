## Overview

Walletwise is an intelligent AI-powered personal finance management application designed to help users take control of their financial goals, track expenses, and make data-driven financial decisions. Built with modern web technologies and powered by advanced AI capabilities, Walletwise provides a seamless and intuitive user experience for comprehensive financial management.

## Key Features

- 💰 **Expense Tracking** - Monitor and categorize your spending with ease
- 🤖 **AI-Powered Insights** - Get intelligent recommendations and financial analysis
- 📊 **Financial Dashboard** - Visualize your financial health at a glance
- 🎯 **Budget Management** - Set and track budgets for different spending categories
- 📈 **Financial Goals** - Plan and monitor progress toward your financial objectives
- 🔒 **Secure & Private** - Your financial data is encrypted and protected

## Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js** (v18 or higher)
- **npm** (v9 or higher) or **yarn**

## Getting Started

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Ofuluefranklin07/Walletwise.git
   cd Walletwise
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure environment variables**
   - Create or update the `.env.local` file in the root directory
   - Add your Gemini API key:
     ```
     GEMINI_API_KEY=your_api_key_here
     ```

4. **Run the development server**
   ```bash
   npm run dev
   ```

5. **Access the application**
   - Open your browser and navigate to `http://localhost:3000`

## Environment Configuration

Create a `.env.local` file in the root directory and configure the following variables:

```env
# Gemini API Configuration
GEMINI_API_KEY=your_gemini_api_key_here

# Optional: Additional configuration
NODE_ENV=development
```

To obtain a Gemini API key:
1. Visit [Google AI Studio](https://ai.google.dev/tutorials/setup)
2. Follow the setup instructions
3. Generate your API key
4. Add it to `.env.local`
